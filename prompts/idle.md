# Idle (breathing loop)

Animate this character into a 4x4 spritesheet for an idle animation. Don't just
make the character static or just move the image up and down — make it have a
breathing animation like in video games: a subtle rise and fall of the chest and
shoulders, slight head and weight shift, and gentle secondary motion on hair,
cloth, or accessories. All 16 frames must use the same scale and framing with the
character centered in each cell, and the sequence (left to right, top to bottom)
should loop seamlessly from the last frame back to the first. Make sure the
spritesheet is ready to use. Always use a transparent background.
